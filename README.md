# Smart-FIRIS 🌲🔥
**سامانه هوشمند ارزیابی و پیش‌بینی خطر آتش‌سوزی جنگل‌ها و مراتع استان فارس**

این سامانه با استفاده از روش ترکیب خطی وزن‌دار (WLC) و تلفیق داده‌های هواشناسی، پوشش گیاهی و توپوگرافی، نقشه پهنه‌بندی خطر حریق را با تفکیک مکانی ۶۰ متر تولید می‌کند.

---

## ۱. مدل ریاضی ارزیابی خطر (WLC)

فرمول نهایی محاسبه شاخص خطر:

$$WLC = 100 \times \Big( 0.45 \times F_{FWI} + 0.35 \times F_{Fuel} + 0.20 \times F_{Topo} \Big)$$

### تشریح مؤلفه‌ها و وزن‌ها:
1. **شاخص هواشناسی حریق ($F_{FWI}$ - وزن ۴۵٪):** 
   - متغیر دینامیک و روزانه بر پایه داده‌های پیش‌بینی هواشناسی.
2. **شاخص بار سوخت گیاهی ($F_{Fuel}$ - وزن ۳۵٪):** 
   - لایه پایه و استاتیک ۶۰ متری حاصل از ارزیابی نوع و تراکم پوشش گیاهی.
3. **شاخص توپوگرافی ($F_{Topo}$ - وزن ۲۰٪):** 
   - لایه پایه ۶۰ متری حاصل از مدل رقومی ارتفاع (DEM)، شامل تحلیل شیب و جهت شیب.

---

## ۲. رده‌بندی سطوح خطر حریق

| سطح خطر | دامنه امتیاز (WLC) | شرح وضعیت |
| :---: | :---: | :--- |
| **خیلی کم** | ۰ تا ۲۰ | شرایط پایدار، احتمال وقوع نزدیک به صفر |
| **کم** | ۲۰ تا ۴۰ | رطوبت مناسب، احتمال گسترش بسیار ناچیز |
| **متوسط** | ۴۰ تا ۶۰ | امکان وقوع در مناطق مستعد، نیاز به پایش دوره‌ای |
| **زیاد** | ۶۰ تا ۸۰ | شرایط خشک و مستعد گسترش سریع، آماده‌باش نیروها |
| **بحرانی** | ۸۰ تا ۱۰۰ | خطر انفجاری حریق، وزش باد شدید و لزوم هشدار قرمز |

---

## ۳. ساختار پردازش داده‌ها

- **داده‌های پایه (Static Layers):** تفکیک مکانی ۶۰ متر منطبق بر Master Grid
- **داده‌های روزانه (Dynamic):** درونیابی نرم (RBF/IDW) جهت انطباق داده‌های اقلیمی بر شبکه ۶۰ متری
- **سیستم مختصات:** EPSG:4326 (WGS 84)
